## **Реализованные фрагменты и функционал**

### **Фрагменты аутентификации**
1. **AuthFragment** — вход (логин/пароль)
2. **RegistrationFragment** — регистрация с загрузкой аватара

### **Основные фрагменты (нижнее меню)**
3. **FeedFragment** — лента постов с пагинацией
4. **EventsFeedFragment** — лента событий с пагинацией
5. **UsersFeedFragment** — список всех пользователей с локальной пагинацией

### **Фрагменты создания/редактирования**
6. **NewPostFragment** — создание/редактирование постов
   - Загрузка фото
   - Сохранение черновиков в SharedPreferences
   - Поддержка редактирования

7. **EventNewFragment** — создание/редактирование событий
   - Выбор даты/времени (BottomSheet)
   - Выбор типа (ONLINE/OFFLINE)
   - Добавление координат на карте

### **Фрагменты детализации**
8. **PostDetailFragment** — детали поста
   - Показ на карте (Яндекс MapKit)
   - Список упомянутых пользователей
   - Список лайков

9. **EventDetailFragment** — детали события
   - Карта с координатами
   - Список спикеров
   - Список участников
   - Список лайков

### **Фрагменты профиля пользователя**
10. **UserFragment** — профиль пользователя (контейнер с TabLayout)
11. **UserWallFragment** — стена постов пользователя (вкладка 1)
12. **UserJobsFragment** — список работ пользователя (вкладка 2)

### **Вспомогательные фрагменты**
13. **MapPickerFragment** — выбор координат события на карте

## **Реализованный функционал по категориям**

### **Авторизация & Регистрация**
- Логин/пароль
- Регистрация с аватаром
- Хранение токена в AppAuth
- Refresh после логина

### **Посты**
- CRUD операции
- Лайки
- Пагинация (Paging 3)
- Загрузка фото
- Сохранение черновиков
- Редактирование
- Общая лента + стена пользователя
- Упоминания пользователей
- Координаты (Яндекс MapKit)
- Поделиться

### **События**
- CRUD операции
- Лайки
- Участие (Join/Leave)
- Пагинация
- Загрузка фото
- Выбор даты/времени события
- Тип события (ONLINE/OFFLINE)
- Координаты на карте
- Список спикеров
- Список участников
- Поделиться

### **Пользователи**
- Список всех пользователей
- Профиль с табами (стена + работы)
- Загрузка аватара
- Отображение работ

### **Хранилище данных**
- Room Database (SQLite)
  - PostEntity, EventEntity, UserEntity
  - RemoteKey таблицы для пагинации
- Type Converters (Gson) для сложных типов
- Paging 3 для локальной пагинации

### **Сеть**
- Retrofit + OkHttp
- Перехватчики для авторизации
- HTTP логирование (debug режим)
- Загрузка медиа (multipart)

### **Архитектура**
- MVVM с LiveData/StateFlow
- Hilt для DI
- Navigation компонент
- BindingAdapter для загрузки изображений (Glide)
